                        Settings

                        Each switch says what it changes. Nothing here reaches a network.

                        Local mode. This version makes no network request and sends no message or attachment to any external service. The only outbound channel is the Native Messaging host on this machine, and only when the Desktop bridge below is on.

                        Effects on your mailbox

                        Automatic Thunderbird tagging

                        Off by default. In Preview mode messages are analysed and displayed without their tags changing.

                        CIVION Desktop bridge

                        Sends candidate-only JSON packages through the local Native Messaging host. No network request is made.

                        Archive recognised PDF documents

                        Stores validated PDFs only below F:\01_ARCHIVE\CIVION. If drive F: is unavailable the document stays pending; there is no fallback to Downloads.

                        Analyse new messages in Junk

                        A junk message is admitted only through the registry identity path or a proven personal history, and the record always carries the marker.

                        Storage and limits

                        Closed-record retention

                        Days a closed record is kept before it is eligible for removal.

                        Maximum number of records

                        A soft target. Closed records go first; active records are never removed for the cap alone.

                        Diagnostics

                        Detailed diagnostic log

                        Without message content. Credentials, tokens, full bodies and attachment text are never written.

                        Trust and identity

                        Trusted authserv-id values

                        The service identifier from the first Authentication-Results header your provider adds — see System → Health → Observed authserv-id. Without this list, authentication results are observational only and no sender is marked verified. Trust assumes your provider strips or renames foreign Authentication-Results headers; that is standard behaviour, but verify it for yours.
